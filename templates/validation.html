Viva & Exam Highlights (Unit III Syllabus)

Embedding vs. Referencing in this Project

  • Embedded: exercises are embedded inside workouts because exercises are always retrieved together with the session (1-to-few relationship).
  • Embedded: body_metrics and membership are embedded inside members for single-read speed.
  • Referenced: trainer_name and plan_name are referenced to prevent data duplication and simplify bulk pricing/trainer updates.

Schema Validation Levels & Actions

  • validationLevel: 'strict' (default) — applies validation rules to all inserts and updates.
  • validationAction: 'error' — rejects any document that violates schema with a WriteError.
  • validationAction: 'warn' — allows write but records a violation in the MongoDB server log.
  • This project uses error action for zero data corruption.
